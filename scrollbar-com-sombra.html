Barra de rolagem (scrollbar) com sombra

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem (scrollbar) colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

::-webkit-scrollbar {width:20px; height:20px;} /* barra de rolagem toda */
::-webkit-scrollbar-thumb {background:pink; box-shadow:1px 1px 10px inset deeppink;} /* parte da barra que se movimenta */
::-webkit-scrollbar-thumb:hover {background:lightgreen; box-shadow:1px 1px 10px inset green;} /* mouse sobre parte da barra que se movimenta */
::-webkit-scrollbar-thumb:active {background:lightblue; box-shadow:1px 1px 10px inset dodgerblue;} /* clique sobre parte da barra que se movimenta*/
::-webkit-scrollbar-track {background:#ffffff;} /* fundo da barra de rolagem, parte fixa */
