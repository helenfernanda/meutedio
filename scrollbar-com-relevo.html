Barra de rolagem com relevo

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

::-webkit-scrollbar {width:15px; height:15px;} /* barra de rolagem toda */
::-webkit-scrollbar-button {background:chocolate; border:5px outset chocolate;height:15px; width:15px;} /* botões da barra de rolagem */
::-webkit-scrollbar-button:hover {background:chocolate; border:5px inset chocolate;} /* mouse sobre o botão da barra de rolagem */
::-webkit-scrollbar-button:active {background:chocolate; border:5px ridge chocolate;} /* clique no botão da barra de rolagem */
::-webkit-scrollbar-thumb {background:chocolate; border:5px outset chocolate;} /* parte da barra de rolagem que desliza */
::-webkit-scrollbar-thumb:hover {background:chocolate; border:5px inset chocolate;} /* mouse sobre parte da barra de rolagem que desliza */
::-webkit-scrollbar-thumb:active {background:chocolate; border:5px ridge chocolate;} /* clique na parte da barra de rolagem que desliza */
