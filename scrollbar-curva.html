Barra de rolagem curva

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

::-webkit-scrollbar {width:25px; height:25px; border-radius:25px;} /* barra de rolagem toda */
::-webkit-scrollbar-button {height:25px; width:25px;border:1px solid #fc0; border-right:5px solid #fc0; border-bottom:5px solid #fc0;border-radius:25px;outline:1px solid #ffc;background:#ffffcc;} /* botões da barra de rolagem */
::-webkit-scrollbar-button:hover {border:1px solid #fc0; border-top:5px solid #fc0; border-left:5px solid #fc0;} /* botões da barra de rolagem quando o mouse passa por cima */
::-webkit-scrollbar-button:active {border:1px ridge #fc0; border-top:5px ridge #fc0; border-left:5px ridge #fc0;} /* botões da barra de rolagem quando o mouse clica neles */
::-webkit-scrollbar-thumb {border:1px solid #fc0; border-right:5px solid #fc0; border-bottom:5px solid #fc0;border-radius:25px;outline:1px solid #ffc;background:#ffffcc;} /* parte da barra de rolagem que desliza */
::-webkit-scrollbar-thumb:hover {border:1px solid #fc0; border-top:5px solid #fc0; border-left:5px solid #fc0;} /* parte da barra de rolagem que desliza quando o mouse passa por cima */
::-webkit-scrollbar-thumb:active {border:1px ridge #fc0; border-top:5px ridge #fc0; border-left:5px ridge #fc0;} /* mouse clica na parte da barra de rolagem que desliza */
