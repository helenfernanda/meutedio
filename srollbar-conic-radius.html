Barra de rolagem com conic-gradient

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

/* */
::-webkit-scrollbar {width:20px; height:20px; text-decoration:underline 1px solid #0f0;} /* barra de rolagem toda */
::-webkit-scrollbar-button {width:20px; height:20px; border-radius:20px; background-image: repeating-conic-gradient(orange 1%, purple 15%);} /* botões da barra de rolagem */
::-webkit-scrollbar-button:hover {background-image: repeating-conic-gradient(purple 1%, orange 15%);} /* mouse sobre o botão da barra de rolagem */
::-webkit-scrollbar-button:active {background-image: repeating-conic-gradient(orange 1%, purple 15%);} /* clique no botão da barra de rolagem */
::-webkit-scrollbar-thumb {background-color:orange; background-image: linear-gradient(to right,orange,purple);border-radius:20px;} /* parte da barra de rolagem que desliza */
::-webkit-scrollbar-thumb:hover {background-image:linear-gradient(to left,orange, purple);} /* mouse sobre parte da barra de rolagem que desliza */
::-webkit-scrollbar-thumb:active {background-image: repeating-conic-gradient(orange 10%, purple 20%);border-radius:20px;} /* clique na parte da barra de rolagem que desliza */
/* */
