Barra de rolagem horizontal diferente da vertical

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem com diferentes cores na vertical, na horizontal e também nos quatro botões. Para ver todas as personalizações, deve usar Google Chrome ou outro navegador desktop que use webkit. As versões mobile não exibem os botões coloridos.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

    /* barra de rolagem começa aqui - meuted.io */
::-webkit-scrollbar {width:10px; height:10px;} /* barra de rolagem toda */
::-webkit-scrollbar-button {width:10px;height:10px;} /* botão da barra de rolagem */
::-webkit-scrollbar-thumb:horizontal {background:antiquewhite;} /* parte móvel horizontal */
::-webkit-scrollbar-thumb:vertical {background:#dce9be;} /* parte móvel vertical */
::-webkit-scrollbar-thumb:horizontal:hover {background:pink;} /* mouse sobre parte móvel horizontal */
::-webkit-scrollbar-thumb:vertical:hover {background:#ac9;} /* mouse sobre parte móvel vertical */
::-webkit-scrollbar-button:horizontal:start {background:red;} /* botão horizontal esquerdo */
::-webkit-scrollbar-button:horizontal:end {background:magenta;} /* botão horizontal direito */
::-webkit-scrollbar-button:vertical:start {background:green;} /* botão vertical superior */
::-webkit-scrollbar-button:vertical:end {background:purple;} /* botão vertical inferior */
::-webkit-scrollbar-button:hover {border:1.4px outset #666;} /* mouse sobre botão da barra de rolagem */
::-webkit-scrollbar-button:active {border:1.4px inset #666;} /* clique sobre botão da barra de rolagem */
    /* barra de rolagem termina aqui - meuted.io */
