Barra de rolagem (scrollbar) com borda

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem (scrollbar) colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

::-webkit-scrollbar {background:#ffffff; width:20px; height:20px;} /* barra de rolagem toda */
::-webkit-scrollbar-thumb {background:lightyellow; border:2px dashed orange;} /* parte da barra que se movimenta */
::-webkit-scrollbar-corner {background:#ffffff;} /* canto inferior direito da barra de rolagem */
::-webkit-scrollbar-track {background:#ffffff;} /* fundo da barra de rolagem, parte fixa */
