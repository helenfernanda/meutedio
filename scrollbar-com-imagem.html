Barra de rolagem (scrollbar) com imagem

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem (scrollbar) colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

::-webkit-scrollbar {width:30px; height:30px;} /* barra de rolagem toda */
::-webkit-scrollbar-thumb {background:orange url(http://meutedio.freetzi.com/bg-para-barra.png) repeat;} /* parte móvel da barra de rolagem */
::-webkit-scrollbar-track {background:#ffffff;} /* fundo da barra de rolagem */
::-webkit-scrollbar-corner {background:orange url(http://meutedio.freetzi.com/bg-para-barra.png) repeat;} /* canto da barra de rolagem */

Onde está escrito http://meutedio.freetzi.com/bg-para-barra.png você coloca o endereço da imagem de sua preferência. A que uso neste exemplo é do site Colour Lovers.
