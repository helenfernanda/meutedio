Barra de rolagem “pedra curva”

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

    ::-webkit-scrollbar {width:20px; height:20px; border-radius:20px;} /* barra de rolagem toda */
    ::-webkit-scrollbar-button {border:5px ridge #ccc; height:20px; width:20px;background:#ccc;border-radius:20px;} /* pontas da barra de rolagem */
    ::-webkit-scrollbar-button:hover {border:5px ridge #999; background:#999;border-radius:20px;} /* mouse sobre pontas da barra de rolagem */
    ::-webkit-scrollbar-button:active {border:3px outset #ccc;background:#ccc;border-radius:20px;} /* clique sobre as pontas da barra de rolagem */
    ::-webkit-scrollbar-thumb {border:5px ridge #ccc; background:#ccc;border-radius:20px;} /* parte da barra que se movimenta */
    ::-webkit-scrollbar-thumb:hover {border:5px ridge #999; background:#999;border-radius:20px;} /* mouse sobre parte da barra que se movimenta */
    ::-webkit-scrollbar-thumb:active {border:3px outset #ccc;background:#ccc;border-radius:20px;} /* clique sobre parte da barra que se movimenta */
