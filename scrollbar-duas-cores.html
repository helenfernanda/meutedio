Barra de rolagem com duas cores (ridge e groove)

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem com duas cores usando bordas ridge e groove. Deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

    /* barra de rolagem começa aqui - meuted.io */
::-webkit-scrollbar {width:24px; height:24px; background:transparent;} /* barra de rolagem toda */
::-webkit-scrollbar-thumb {border:0;} /* parte móvel */
::-webkit-scrollbar-thumb:horizontal {border-bottom:12px ridge greenyellow;} /* parte móvel horizontal */
::-webkit-scrollbar-thumb:vertical {border-right:12px ridge greenyellow;} /* parte móvel vertical */
::-webkit-scrollbar-thumb:hover {border-style:groove;} /* mouse sobre parte móvel */
::-webkit-scrollbar-thumb:active {border-color:#B94E48;} /* clique sobre parte móvel */
    /* barra de rolagem termina aqui - meuted.io */
