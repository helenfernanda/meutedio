Barra de rolagem com tamanhos diferentes

Neste exempolo, a barra horizontal é mais estreita que a vertical.

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

::-webkit-scrollbar {width:15px; height:10px;} /* barra de rolagem toda */
::-webkit-scrollbar-thumb {background:linear-gradient(45deg in oklch longer hue,#f0f,#000); border:1px solid white;} /* parte da barra que se movimenta */
::-webkit-scrollbar-thumb:hover {background:linear-gradient(45deg,#f0f,#000);} /* mouse sobre parte da barra que se movimenta */
::-webkit-scrollbar-thumb:active {background:linear-gradient(45deg in oklch longer hue,#000,#f0f);} /* clique sobre parte da barra que se movimenta */
