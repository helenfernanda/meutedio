Barra de rolagem com duas linhas

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

/* barra de rolagem começa aqui - meuted.io */
::-webkit-scrollbar {width:8px; height:8px;} /* barra de rolagem toda */
::-webkit-scrollbar-thumb:vertical {border-left:5px double olive;} /* parte móvel vertical */
::-webkit-scrollbar-thumb:horizontal {border-bottom:5px double olive;} /* parte móvel horizontal */
::-webkit-scrollbar-thumb:hover {border-color:dodgerblue;} /* mouse sobre parte móvel */
::-webkit-scrollbar-thumb:active {border-color:orchid;} /* clique sobre parte móvel */
/* barra de rolagem termina aqui - meuted.io */
