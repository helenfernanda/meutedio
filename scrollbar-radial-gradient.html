Barra de rolagem com radial-gradient

Esta página é um anexo do post CSS: barra de rolagem colorida com ::webkit-scrollbar.

Aqui temos um exemplo de barra de rolagem colorida que deve funcionar no Google Chrome e em outros navegadores desktop que usam webkit.

Para um método mais atual e que funciona em todos os navegadores, use scrollbar-color.

Código para a folha de estilos:

::-webkit-scrollbar {width:20px; height:20px;} /* barra de rolagem toda */
::-webkit-scrollbar-thumb {background:repeating-radial-gradient(magenta, gold 10%);border-radius:20px; width:20px; height:20px; border:1px outset magenta;} /* parte móvel da barra de rolagem */
::-webkit-scrollbar-thumb:hover {background:repeating-radial-gradient(gold, magenta 10%);} /* mouse sobre parte móvel barra de rolagem */
::-webkit-scrollbar-thumb:active {background:repeating-radial-gradient(orange, purple 10%);} /* clique sobre parte móvel da barra de rolagem */
::-webkit-scrollbar-button {background:repeating-radial-gradient(magenta, gold 30%);border-radius:20px; width:20px; height:20px;border:1px outset magenta;} /* botões da barra de rolagem */
::-webkit-scrollbar-button:hover {background:repeating-radial-gradient(gold, magenta 30%);} /* mouse sobre botões */
::-webkit-scrollbar-button:active {background:repeating-radial-gradient(orange, purple 10%);} /* clique no botão */
